## Pour lancer le projet avec clion : 
- Ouvrer clion
- Créer un nouveau projet "C++ executable"
- supprimer tous ce qui vient d'être créer sauf le dossier "cmake-build-debug"
- Exécuter la commande "git clone https://github.com/NatsuFire6/InterestCalculator.git" dans le terminal lier à ce projet
- sorter tous ce qu'il y a dans le fichier qui viens d'être créer
- modifier comme bon vous semble la fonction main du fichier "interestCalculator.cpp"
- éxécuter le programme

## pour lancer le projet dans vscode ou sans IDE
- Créer un nouveau dossier
- ouvrer le terminal de ce dossier
- éxécuter la commande "git clone https://github.com/NatsuFire6/InterestCalculator.git"
- éxécuter la commande "cd .\InterestCalculator\untitled\"
- modifier la fonction main du fichier "interestCalculator.cpp" comme bon vous semble
- éxécuter la commande "g++ -std=c++20 -Wall -Wextra *.cpp -o prog"
- éxécuter la commande ".\prog.exe"
